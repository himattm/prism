# Code of Conduct

## Our Standards

We are committed to providing a welcoming and inclusive environment. All participants are expected to:

- Be respectful and considerate
- Accept constructive feedback gracefully
- Focus on collaboration and the project's best interests

## Reporting

If you experience or witness unacceptable behavior, please open an issue at [github.com/himattm/prism/issues](https://github.com/himattm/prism/issues).

## Scope

This code of conduct applies to all project spaces including issues, pull requests, and discussions.
