## 2025-05-08 - Path Traversal Vulnerability in Plugin Manager
**Vulnerability:** A path traversal vulnerability exists in `internal/plugin/manager.go` in multiple functions (`addFromDirectURL`, `Remove`) where an untrusted plugin name is interpolated directly into a file path using `filepath.Join` without sufficient sanitization. For example, `filepath.Join(m.pluginDir, fmt.Sprintf("prism-plugin-%s.sh", pluginName))` where `pluginName` can be `../../../evil`.
**Learning:** `filepath.Join` calls `filepath.Clean` internally, which evaluates `../` sequences. Thus, `filepath.Join("/dir", "prefix-../../../evil.sh")` results in `/evil.sh`, escaping the intended directory.
**Prevention:** Sanitize untrusted input before using it in file paths. A robust way to prevent path traversal when constructing filenames is to extract just the base name, and to strip out any characters that could allow escaping the directory (such as slashes). For instance, use `filepath.Base(filepath.Clean("/" + name))` and ensure the name does not equal `.` or `..` or `/`.
