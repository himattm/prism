
## 2024-05-20 - Atomic Write Symlink Attack Vulnerability
**Vulnerability:** File caching functions (`saveUpdateCache`, `saveUsageCache`) were using `os.WriteFile` with a predictable file path in a shared directory (`os.TempDir()`), which is susceptible to symlink attacks.
**Learning:** `os.WriteFile` overwrites files if they exist. If a malicious user creates a symlink at the predictable temporary file path pointing to a sensitive file, `os.WriteFile` will write the data to the target of the symlink, potentially overwriting sensitive files or leading to privilege escalation. Furthermore, if `os.Rename` is used with `os.CreateTemp(os.TempDir(), ...)`, it will fail if `os.TempDir()` is on a different filesystem partition than the target file directory.
**Prevention:** Use an atomic "write-to-temp-and-rename" pattern. Securely create the temporary file using `os.CreateTemp(filepath.Dir(targetPath), ...)`, which inherently handles creating non-predictable filenames, prevents cross-device rename issues, and sets restrictive permissions. Write data, chmod to the desired permissions, close the file, and then atomically `os.Rename` it to the target path. Add a `defer os.Remove(tmpName)` to ensure cleanup.
