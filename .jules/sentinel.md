## 2025-02-14 - Fix Predictable Temporary File Names (Symlink vulnerability in Atomic Saves)
**Vulnerability:** Found predictably named temporary files created during atomic save operations (`path + ".tmp"`), which could be leveraged to carry out symlink attacks and overwrite unintended files when writing config/cache states.
**Learning:** This repo utilized a custom atomic-write pattern that hardcoded the intermediate temporary file names, neglecting security implications of predictable caching locations, especially those under globally writable paths like `/tmp`.
**Prevention:** Avoid manually suffixing paths for temporary files. Instead, leverage `os.CreateTemp(filepath.Dir(path), filepath.Base(path)+".*.tmp")` which provides collision-free temporary file creation through random naming while respecting directory locality required for atomic `os.Rename`. Always explicitly call `f.Chmod` when using `CreateTemp` if the desired file should be group/world-readable (since it defaults to 0600).
